Free Tulu fonts

Five fonts for Tulu lipi, all designed by Prahlad Prasad Tantry and free under the SIL Open Font License 1.1. One is a Unicode font; four are ASCII fonts typed with the AccTantra key map.

Mallige and Mallige Unicode are the faithful representations of the standard for writing Tuḷu set out in Tuḷu Varṇāmr̥ta. The same work is being extended to the other fonts, and they are being ported to Unicode as well, except for Allige, which was forked from Mallige.

Faithful to the standard as Unicode: 86 Tulu-Tigalari characters, with OpenType shaping.

Installing a font

Windows: right-click the font file and choose Install. macOS: open the file and click Install Font. Linux: copy it to ~/.local/share/fonts/ and run fc-cache -f.
