Tulu Unicode font: Mallige Unicode

Mallige Unicode is a free Unicode font for the Tulu-Tigalari script (Unicode 16.0), designed by Prahlad Prasad Tantry. Text typed with it is real Unicode text: it can be searched, copied and shown in any font that supports the script.

Mallige Unicode is the Unicode counterpart of Mallige, and together they are the faithful representations of the standard for writing Tuḷu set out in Tuḷu Varṇāmr̥ta.

How to type with it

Install the AccTantra Unicode keyboard for Keyman, which produces real Tulu-Tigalari characters for this font. To convert existing text, use the Tulu transliterator.

Conjuncts and mark positions need an application with OpenType shaping support, such as one built on HarfBuzz, DirectWrite, CoreText or Uniscribe.
