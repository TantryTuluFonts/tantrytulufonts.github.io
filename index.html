The book and the standard

Tuḷu Varṇāmr̥ta

A Prescriptive Primer to the Tuḷu Script

Everything you need to read and write the traditional Tuḷu script, in one book. It also sets out the standard for writing Tuḷu that the language has long lacked: the traditional script kept exactly as it is, and still ready for modern Tuḷu.

Common questions

Is there a Unicode font for Tulu?

Yes. Mallige Unicode is a free Unicode font for the Tulu-Tigalari script (Unicode 16.0), with OpenType shaping for conjuncts and marks.

How do I type in Tulu?

For real Unicode text, install the AccTantra Unicode keyboard for Keyman. For the ASCII fonts, type with the AccTantra key map on any keyboard.

Are the Tulu fonts free?

Yes. All of them are released under the SIL Open Font License 1.1: free to use, study, share and modify, as long as they are not sold on their own.

Is there a standard for writing the Tulu script?

Yes. Tuḷu Varṇāmr̥ta by Prahlad Prasad Tantry sets out one rule-governed orthography for the traditional Tuḷu script, and this page explains why it should be maintained.

Who designs these fonts?

All of them are designed by Prahlad Prasad Tantry.
