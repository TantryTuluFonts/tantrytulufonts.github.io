AccTantra: how to type Tulu with ASCII fonts

AccTantra is a typing standard for the Tulu language on ASCII-based fonts, created by Prahlad Prasad Tantry. You type with an ordinary keyboard, and an AccTantra font draws the Tulu letters. Because every font follows the same key map, text written for one font works in all of them.

Try it

Type EAamAX nEma narayNay and every AccTantra font shows Om namo Narayanaya:

The name

Accu means to press or print, and Tantra means a text, theory, system or method. AccTantra means "the doctrine of printing".
