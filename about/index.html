Prahlad Prasad Tantry

Prahlad Prasad Tantry (also written Prahlad Tantri) is the type designer behind the Tantry Tulu Font Foundry. He designed every font published here, along with the typing standard and keyboard that go with them.

What he has made

  • Darage, Mandara, Allige and Mallige: ASCII fonts for Tulu lipi, typed with one shared key map
  • Mallige Unicode: a Unicode font for the Tulu-Tigalari script
  • AccTantra: the typing standard that makes the ASCII fonts interchangeable
  • AccTantra Unicode: a Keyman keyboard for Tulu-Tigalari
  • Tulu transliterator: a converter between AccTantra text and IAST, Devanagari, Kannada and Malayalam

Authorship

Prahlad Prasad Tantry is the designer and copyright holder of all of these fonts. Every repository lists him as the author. If you use the fonts, please keep that credit.
