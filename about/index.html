Prahlad Prasad Tantry

Prahlad Prasad Tantry (also written Prahlad Tantri) is a type designer who makes fonts and typing tools for the Tulu language. He designed every font published by the Tantry Tulu Font Foundry, along with the typing standard and the keyboard that go with them.

His aim is simple: make it easy to write Tulu on a screen, in its own script, with tools that anyone can use for free.

His work, in order

  1. 2020
    Darage

    The first of the family. An OpenType font for Tulu lipi, with its editable Glyphs source.

  2. 2021
    Mandara

    A bold, rounded ASCII font for Tulu lipi.

  3. 2022
    Allige and Mallige

    The Academy edition, and Mallige, which grew into the largest set of conjuncts in the family.

  4. January 2025
    AccTantra

    One key map for every ASCII Tulu font, so text typed once works in all of them.

  5. March 2026
    Tulu transliterator

    A converter between AccTantra text, IAST, Devanagari, Kannada and Malayalam.

  6. July 2026
    Mallige Unicode and the AccTantra Unicode keyboard

    A Unicode font and a Keyman keyboard for the Tulu-Tigalari script, so Tulu can be typed and stored as real text.

  7. November 2026
    The foundry

    Everything brought together as the Tantry Tulu Font Foundry, free under the SIL Open Font License.

Dates for the older fonts come from the version records in the font files; the rest come from when each project was first published.

What he has made

Five Tulu fonts

Darage, Mandara, Allige, Mallige and the Unicode font Mallige Unicode.

AccTantra

The typing standard that makes every ASCII Tulu font interchangeable.

A Tulu keyboard

A Keyman keyboard for typing Tulu-Tigalari as Unicode.
