# Tantry Tulu Font Foundry website

The source of <https://tantrytulufonts.github.io>: free Tulu fonts, a Tulu Unicode font, a Tulu keyboard and the AccTantra typing standard, all designed by Prahlad Prasad Tantry.

Static pages, no build step. Licensed under the SIL Open Font License 1.1 where applicable to the fonts; site text and images are by Prahlad Prasad Tantry.
