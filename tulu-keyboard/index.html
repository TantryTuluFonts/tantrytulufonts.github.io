Tulu keyboard: AccTantra Unicode

The AccTantra Unicode keyboard lets you type the Tulu-Tigalari script on a normal keyboard. It runs on Keyman and was created by Prahlad Prasad Tantry.

Get the keyboard Get the Unicode font

At a glance

PropertyValue
EngineKeyman 15.0 or later
ScriptTulu-Tigalari (Unicode U+11380 to U+113FF)
Keyboard version1.4.2
OutputReal Unicode text, so it can be searched and copied
LicenseSIL Open Font License 1.1

Using it

Install the keyboard in Keyman, then install a Unicode font that supports the script, such as Mallige Unicode, so the characters display. The full typing guide, with every key, is in the keyboard repository.

Need to convert existing text? The Tulu transliterator converts between AccTantra text, IAST, Devanagari, Kannada and Malayalam.
